OutlookRegister 使用说明
========================

一、安装
--------
1. 把整个文件夹解压到有写权限的位置，例如 D:\OutlookRegister
   不要放在 C:\Program Files 下 —— 那里没有写权限，配置和注册结果会保存失败。
   程序启动时会自检，若不可写会直接提示。

2. 无需安装 Python，无需安装浏览器，Chromium 已内置。

二、启动
--------
双击 OutlookRegister.exe

程序会：
  - 首次运行自动生成 config.json（从 config.example.json 复制）
  - 启动本地 Web 控制台并自动打开浏览器
  - 地址：http://127.0.0.1:9090

控制台只监听本机 127.0.0.1，局域网和外网都访问不到。
首次访问需要在网页上创建管理员账号和密码。

关闭那个黑色命令行窗口即退出程序。

三、配置
--------
在控制台的「系统设置」里填写。至少要配好代理：

  代理模式  single  = 用单个端口
            multiple = 用端口区间（需要配合本地代理池）
  代理主机  一般是 127.0.0.1

其他常用项：
  验证码策略  0 = 全自动
              1 = 你手动过验证码，其余自动
              2 = 出现验证码后交人工，该任务不跑 OAuth
  浏览器指纹  建议开启，降低自动化特征
  无头模式    建议关闭（显示窗口），便于观察和人工介入

如果要用辅助邮箱自动绑定，需要自备临时邮箱服务并在 temp_mail 里配好。

四、开始注册
------------
「启动注册」页面填写注册数量和并发数，点开始。

  - 实时日志会在页面上滚动
  - 点「停止」会先写出统计汇总、再关浏览器并清理临时 profile，
    请耐心等几秒，不要直接关窗口

五、结果文件
------------
Results\oauth2.txt          注册成功的账号
                            格式：邮箱----密码----client_id----refresh_token
Results\recovery_emails.txt  账号与辅助邮箱的绑定关系
log\                         运行日志，按时间分文件

这些文件在程序更新时不会被覆盖。

六、更新
--------
不会自动更新。在「关于与更新」页面点「检查更新」。

流程：检查 → 下载 → 校验 → 点「立即重启并更新」。
程序会自行退出、覆盖程序文件、然后重新启动。

更新时以下内容一律保留：
  config.json、admin.json、Results\、log\、browser_profiles\、browsers\

更新前请先停止正在运行的注册任务，否则程序文件被占用会导致更新失败。
如果 GitHub 连不上，程序会尝试用你配置的注册代理去访问。

七、常见问题
------------
Q: 双击没反应 / 窗口闪一下就没了
A: 在文件夹里按住 Shift 右键 → 在此处打开 PowerShell，执行
   .\OutlookRegister.exe
   这样能看到报错信息。

Q: 杀毒软件报毒
A: PyInstaller 打包的程序 + 浏览器自动化容易被误报，且本程序未做代码签名。
   如不放心请自行用源码运行。

Q: 端口 9090 被占用
A: 命令行启动时加参数：.\OutlookRegister.exe --console --port 9099

Q: 提示目录不可写
A: 把整个文件夹移到 D 盘等有写权限的位置，不要放 C:\Program Files。
